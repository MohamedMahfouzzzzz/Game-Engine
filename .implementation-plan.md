- `engine/gd_lang/dictionaries.py` - Key-value data
- `engine/gd_lang/type_system.py` - Type validation

**Features:**
- Typed arrays with runtime checks
- Dictionary/map support

### 1.3 Core Encryption System
**Files to Create:**
- `engine/security/crypto_manager.py` - AES encryption wrapper
- `engine/security/key_manager.py` - Key generation/storage
- `engine/io/encrypted_format.py` - Encrypted save format

**Features:**
- AES-256 encryption for save files

- Encrypted binary format (.ges_encrypted)
- Decryption on load with integrity checking

1. **Project initialization** (foundation for everything)
2. **Database + encryption** (core data persistence)

4. **Telemetry system** (monitoring infrastructure)

6. **Dialogue manager** (content tool)
7. **Export pipeline** (build system)
8. **Pixel scaling** (graphics optimization)
9. **Debug system** (validation/tooling)
